2. Sound & Function Mapping (The Crucial Part)
The Econami decoder packs its sound layers into the standard DCC functions. To activate them from your custom React UI, your Python backend must send function status updates using: <f CAB BYTE1 BYTE2>
Because DCC-EX handles functions in grouped bytes (F0–F28), you must calculate the binary state of the buttons toggled on your React UI. The layout for the Econami Steam decoder functions looks like this:
React UI Button	Sound / Feature	DCC-EX Function Group
F0	Headlight (Directional)	Group 1 (F0 - F4)

F2	Whistle / Horn (Authentic UP Whistle)	Group 1 (F0 - F4)
F3	Short Whistle / Chuff Mute Toggle	Group 1 (F0 - F4)
F4	Cylinder Cocks (Steam blow-down hiss)	Group 1 (F0 - F4)

def send_dcc_function(cab_address, group, functions_dict):
    """
    cab_address: int (e.g., 37)
    group: int (1 for F0-F4, 2 for F5-F8)
    functions_dict: dict of booleans showing active buttons e.g., {'F0': True, 'F1': False}
    """
    byte_value = 0
    
    if group == 1:
        # Group 1 format: Bit 4=F0, Bit 0=F1, Bit 1=F2, Bit 2=F3, Bit 3=F4
        if functions_dict.get('F0', False): byte_value |= 0x10
        if functions_dict.get('F1', False): byte_value |= 0x01
        if functions_dict.get('F2', False): byte_value |= 0x02
        if functions_dict.get('F3', False): byte_value |= 0x04
        if functions_dict.get('F4', False): byte_value |= 0x08
        # DCC-EX Command Code for Group 1 functions is 128 + byte_value
        command = f"<f {cab_address} {128 + byte_value}>"
        
    elif group == 2:
        # Group 2 format: Bit 0=F5, Bit 1=F6, Bit 2=F7, Bit 3=F8
        if functions_dict.get('F5', False): byte_value |= 0x01
        if functions_dict.get('F6', False): byte_value |= 0x02
        if functions_dict.get('F7', False): byte_value |= 0x04
        if functions_dict.get('F8', False): byte_value |= 0x08
        # DCC-EX Command Code for Group 2 functions is 176 + byte_value
        command = f"<f {cab_address} {176 + byte_value}>"

    serial_port.write(command.encode('utf-8'))
